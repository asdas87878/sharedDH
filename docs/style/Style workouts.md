# Style workouts

Small, specific tests of how the game looks, one note each, numbered. Each one ends with options for the user to pick from;
the picks go in [Decisions](../Decisions.md).

**Inspiration (decided 2026-11-09):** Ride a Dino's broad style: chunky shapes, bright readable colour, cheap to make. Our own
creatures, palette and world, never its models or layout.

| 2 | [Creature look](02-creature-look.md) | How do the creatures look? The Sergeant Major built by the [creature method](creature-method.md) from the user's ChatGPT concept, ridden, seen at game distance | Head and mouth rebuilt from the user's drawings; good enough for now |
