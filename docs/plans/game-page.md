## Creator Hub checklist (create.roblox.com → Ride a Fish)
Must before it goes public:
- [ ] **Maturity & Compliance questionnaire** (Audience): fill it in, or the game can't be public and gets no rating.
- [ ] **Basic settings:** name, description, **genre** (Simulation, or the closest) and subgenre.
- [ ] **Icon** 512x512 (no text-heavy logos; the Great White or the rider on a fish).
- [ ] **Thumbnails** 1920x1080 (3 to 5 shots; the trailer `work/trailer/trailer.mp4` as a video thumbnail if the account
      can upload videos).
- [ ] **Devices:** Computer, Phone, Tablet on (console only once tested).
- [ ] **Places → start place → Server size** (6 to 8 for a simulator).
- [ ] **Security:** "Enable Studio access to API services" on (done); keep "Allow HTTP requests" off unless the game uses it.
- [ ] **Avatar:** leave as it is (the code handles R15 and R6).
- [ ] **Audience → visibility: Public** (last, after the questionnaire).

Good to set:
- [ ] **Collaborators:** add the partner's account (Edit) so he can publish and see analytics.
- [ ] **Private servers:** on, free or 100 Robux (more Robux, people play with friends).
- [ ] **Localization:** automatic translation on (more players in other languages for free).
- [ ] **Social links:** a Discord or YouTube link if you have one.
- [ ] **Badges:** a few (first fish, first Underworld dive); each costs Robux unless you have free uploads that day.
- [ ] **Notifications** (experience notifications) for "your tank is full" later; needs code.
- [ ] **Monetization → Developer products:** done, 15 on sale. Price optimisation stays off (prices are fixed in the game).
- [ ] **Delete the API key** you pasted in chat (Open Cloud → API Keys).
